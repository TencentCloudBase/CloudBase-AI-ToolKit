# 个人工作台场景模板 Playbook

社区已验证的场景模板目录。需求澄清时从这里挑最接近的起步：字段可以增删，但数据模型骨架别推翻重来。每个模板含四项：场景名（用户口语）、数据模型（表/字段建议）、是否需要多人/登录、交付形态。

## 单人模板

| 场景 | 数据模型（表 + 字段建议） | 多人/登录 | 交付形态 |
| --- | --- | --- | --- |
| 健身打卡 | `checkins`(date, 运动类型, 时长, 感受备注, photo 可选) | 单人免登录，开登录可换设备同步 | 打卡日历 + 连续天数 + 周统计 |
| 背单词打卡 | `words`(word, 意思, 熟练度 1-5) + `reviews`(date, word_id, 记住没) | 单人 | 今日复习队列 + 总进度条 |
| 习惯追踪 | `habits`(name, 频率) + `habit_logs`(habit_id, date, done) | 单人 | 习惯热力网格 + 各习惯完成率 |
| 追剧清单 | `shows`(名称, 状态: 想看/在看/看完, 评分, 短评, 平台) | 单人 | 三栏状态列表 + 评分墙 + 短评时间线 |
| 游戏进度 | `games`(名称, 平台, 进度%, 状态, 备注) | 单人 | 游戏柜 + 进度条列表 |
| 穿搭清单 | `outfits`(单品, 类别, 颜色, 季节, 图片) + `ootd_logs`(date, 单品组合, photo) | 单人 | 衣橱分类页 + 每日穿搭记录流 |
| 情绪记录 | `moods`(date, 情绪分 1-5, 事件标签, 一句话) | 单人 | 情绪日历 + 月度曲线 + 高频标签 |
| 育儿记录 | `events`(类型: 喂奶/睡觉/辅食/身高体重, 时间, 数值, 备注) | 单人；父母共用 → 多人版 | 时间线 + 今日汇总卡（喂了几次/睡了几小时） |
| 周报生成 | `worklogs`(date, 做了什么, 花的时间, 所属项目) | 单人 | 一周流水 + 一键生成周报草稿（`ai-model-web`） |
| 时薪计算 | `shifts`(date, 开始时间, 结束时间, 时薪, 备注) | 单人 | 本月工时 + 收入合计 + 班次列表 |
| 选题库 | `ideas`(标题, 来源, 状态: 想法/待写/已发, 发布链接, 备注) | 单人 | 状态流转列表 + 灵感速记入口 |
| OKR 追踪 | `objectives`(目标, 周期) + `key_results`(kr 描述, 目标值, 当前值) + `updates`(date, 进度说明) | 单人；团队用 → 多人版 | 目标卡 + KR 进度条 + 更新记录 |
| 数据复盘 | `metrics`(date, 指标名, 数值, 来源) | 单人 | 指标趋势图 + 周环比摘要 |
| 记账 | `transactions`(date, 金额, 分类, 方向: 收/支, 备注, 凭证 photo 可选) | 单人免登录 / 开登录换设备同步 | 月度分类汇总 + 流水列表 |

## 多人模板

| 场景 | 数据模型 | 多人/登录 | 交付形态 |
| --- | --- | --- | --- |
| 情侣/家庭记账 | `transactions` 同上 + `created_by`（登录人） | 2 人以上，手机验证码登录 | 双方流水合并视图 + 各自支出统计 + 共同开销合计 |
| 双人打卡监督 | `checkins` + 双方互见 | 2 人，手机验证码登录 | 双方打卡日历并排 + 「TA 今天还没打卡」提醒 |
| 共同清单（购物/装修/旅行） | `items`(内容, 谁加的, 状态: 待办/已办, 谁办完的) | 家庭/小组，手机验证码登录 | 共享清单 + 勾选状态实时可见 + 按人过滤 |

## 「分享开关」升级路径

单人模板默认免登录（最快交付）。当用户说「能不能让 xx 也一起用」时，同一套代码加两样东西就变多人版：

1. **手机验证码登录**：按 agents md 固件环节 B 配置（app-auth patchLoginStrategy + 前端短信登录）
2. **数据按人隔离**：业务表加 `created_by` 字段，RLS 默认「只看自己创建的」；仅家庭共享类表（共同清单）放开全员可读

注意：不要为「可能多人」预先设计登录——先按单人交付，分享需求真正出现时再升级，避免过度设计。
